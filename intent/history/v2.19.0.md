# v2.19.0 -- readers that stop answering confidently from partial evidence

Minor. Fifteen issues closed end to end (0009-0023), no steel thread -- the standing fix-under-issue ruling. The centrepiece is the **AT row grammar** (0017, subsuming 0014 and 0015), and it sets the theme the rest of the release turns out to share.

## The spine

Nearly every defect in this release is one shape: **a reader that recovers part of what it was given, discards the rest, and says nothing.** Not a crash, not a wrong answer loudly given -- a confident partial answer, exit 0, with no way for the caller to tell "correctly filtered" from "silently dropped".

- The **AT reference** was defined as whatever sat inside the first pair of backticks. It was not required to be a path, to contain a directory, to exist, or to be present at all. No row could ever be malformed, only partially recovered, one field at a time (0017).
- Punctuation fused to a **coverage id** (`AC-09.1's`) matched nothing, so the link vanished and rendered identically to never having written it -- the contract reported work uncovered that was done and green (0014).
- A **green AT citing a test file that no longer existed** stayed green forever, so the gate grew _more_ permissive as citations rotted (0015).
- **`steel_threads.md`** was composed from the WIP-only default view, so the canonical index decayed to empty exactly at a release close, when nobody looks (0019).
- **`st list --status all`** walked ten status literals and dropped anything else, and after 0019 that omission reached committed state (0020).
- **`intent st`** treated any `STnnnn` directory at any depth as live, so staging areas -- which characteristically hold copies -- manufactured duplicate ids (0011).
- **`ws hygiene`** never checked that the header block parsed at all: the one channel the protocol specifies as machine-read was the one nothing machine-checked (0012).
- **Six custom Credo checks** were copied into every retrofitted Elixir project and then best-effort wired, so the usual outcome was a directory of checks no runner ever loaded -- compiled into every build for five months on the reporting estate, executed zero times, and by the end not even wirable (0021).
- The **treeindex cache** was tracked, machine-flavoured and stale -- `bin/.treeindex` still described a command retired four releases earlier, so the "project memory" it appeared to be was simply wrong, which is worse than absent (0018).

The fixes share a shape too: make the reader strict, so a non-conforming input yields NO field rather than a plausible wrong one, and then say so out loud.

## The AT row grammar (0017, with 0014 + 0015)

One anchored pattern, two arms: a test arm requiring a backticked repo-relative path, and a non-test arm (`(non-test)` + prose + `status: n/a`) for the doc / eyeball / gate rows the status vocabulary always declared. Every field reader is one line over that pattern. `intent at lint` reports five checks -- **L1** the row matches, **L2** a `green`/`red` row's cited file exists (`to-write` exempt), **L3** the cited file contains the literal AT id, **L4** every covered id is a real AC row, **L5** a non-test AT is not the sole cover for a test-backed AC.

**The one substantive change is that the row links by id rather than by test name.** A cited name is unverifiable -- paraphrase defeats every string match, which is why the reference grew three competing shapes. An id is checkable from both ends.

`--fix` migrates the mechanical half and **refuses what it cannot migrate without loss**. That rule was learned the hard way, three times, all on real-estate evidence rather than review:

1. It scanned the whole repository per non-conforming row (`find -name` per row on a 65GB estate). Worse than the cost: `find -name` takes a glob, and a `[to-write]` placeholder is a character class, so a lone single-character filename was a unique match and the row would have been rewritten to cite an unrelated file.
2. It stripped the test name before the id existed in the test -- breaking the only link the row had, and converting an honest "retired form" finding into a misleading "the file does not carry the id" one, on a row that now read complete and pointed at nothing. Caught by a consumer running it and measuring, not by us.
3. The **lint suggestion was lossy before the fixer was**: it reported everything before the first `::`, so on a two-file row it named one file and silently discarded the other. Anyone hand-following that advice lost exactly what the fixer did.

Our own estate had already been swept with the lossy version. The 87 destroyed name links were measured and restored verbatim from git (`ee44f63`) into trailing notes.

## The rest

- **An AC has four states** (0013 + hv's `withdraw`). `descope --to` / `rescope`, `withdraw --reason` / `reinstate`. Both non-blocking, both reported separately rather than folded into the failure count, each carrying the audit payload that justifies the verb existing. A contract emptied entirely by off-scoping is refused toward the announced `acceptance: exempt` escape -- an exemption is announced, never inferred from emptiness.
- **One steel-thread enumerator** (0011). `list_st_dirs` in helpers; five hand-rolled copies replaced -- **the last two found by a mechanical guard, after both the fix and the audit had read past them.**
- **The whiteboard header block is ruled NOT YAML** (0012), line-oriented `key: value`, quotes literal. The format the tooling implements, the format the nodes write, and the format that reads correctly are the same one; the word "YAML" was the only thing out of step.
- **Hooks resolve at runtime** (0016). `intent claude hook <name>`; `settings.json` byte-identical on every machine. The template had baked one machine's absolute home path into every scaffolded project -- a runtime question answered at write time, frozen into a tracked file, published in a public repository.
- **AGENTS.md prerequisites follow the declared languages** (0009), with the node and bats probe exceptions stated rather than left as apparent oversights.
- **`st done` / `wp done` say so when the Objective was never written** (0010) -- warn, never block, scoped to one section, because a warning that fires on nearly everything is switched off within a day.
- **`st list --status all` means all** (0020). Membership through the synonym table, unplaceable rows shown last and named on stderr. Called in by hv before the cut rather than after.
- **A whole duplicate mechanism deleted** (0021). `intent st zero`'s D5a shipped six custom Credo checks into Elixir consumers to enforce rules the rule library and the critic gate already enforce -- Highlander with the duplicate half left to rot, and it rotted: one of them crashes Credo 1.7.19 by calling a pre-1.7 API. Templates and wiring script deleted, not deprecated; `intent doctor` reports a consumer's residue in three distinct states and names the `elixirc_paths` end too, because removing the directory alone breaks the build. **A check absent from the runner's config is invisible, and its presence in the repo reads as "enforced" to everyone who finds it, which is worse than absence** -- the spine of this release, stated by the consumer who found it.
- **Both no-template fallback heredocs deleted** (0022). `st new` / `wp new` each shadowed a template with a hand-written copy that fired only on a broken install -- so nobody edited them and both drifted: the WP one instructed users to restate ACs in the work package, which its own template forbids, and the ST one produced a thread with no acceptance contract at all. They now fail loudly and name the path. Deleted rather than corrected: correcting restores two copies and buys another year of drift.
- **One voice, finally** (0023, after `8aba5ab`). `warning()` was corrected mid-release; `error()` was the other half and the worse one, because the function whose job is to give failures a single voice was the one setting the wrong example -- 26 sites across the shell CLI were copying it. Swept, guarded on prefix + stream + exit. The plugin bins writing errors to _stdout_ is named and left: that changes what callers capture, not just what they read.

## What consumers should expect

**The close-gate honours the grammar from the day this ships.** An estate written against the old free-form convention gates BLOCKED until swept, and that is the fix working: every row it names was already contributing no coverage, silently. The `at_grammar` ledger step runs the mechanical migration during `intent upgrade`, so a consumer is swept by upgrading rather than by knowing the command. Rows needing a human are reported by name and never guessed at.

## Process, which was half the release

- **Grep for a Highlander rule; never read for it.** 0011 was fixed by repointing the call sites found by reading, and the audit read the same way. A mechanical guard found two more at once.
- **A test that passes is not a test that works.** Seven guards this release would have guarded nothing -- every one caught by mutation, none by review.
- **Diagnose by running, not reading.** Five filed claims fell to three-minute repros, two of them the reviewer's own. Two root causes were corrected before any fix was built.
- **Run the real path in a sacrificial copy.** Four defects surfaced only by exercising; none could have been read.
- **A mutation battery can lie, and it lies in the direction of looking thorough.** 0020's first battery skipped its own restore step and reported an impossible result. Hard-fail a mutation whose substitution did not apply.

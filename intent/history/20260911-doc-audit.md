### The protocol, every lane

1. **As-built is the truth, and the doc moves to the code.** This job writes no code. Where the doc is right and the code is wrong, describe the as-built behaviour and send the defect to vc with `file:line`. vc surfaces it to hv.
2. **Measure every checkable claim.** That covers verb spellings, flags, defaults, paths, output lines, exit codes, config keys and file names. Either drive `intent` read-only or read the code at HEAD and cite `file:line`. Anything that writes runs in a scratch project under an isolated HOME, never in this tree. Recall is not evidence.
3. **Every finding gets one disposition.**
   - **STALE:** rewrite it.
   - **DEAD:** delete it outright, with no "formerly" and no stub.
   - **UNDOCUMENTED:** add it where the reader would look.
   - **CODE-WRONG:** surface it and don't fix it.
4. **Generated files are fixed at their source and regenerated by their verb.** Never hand-edit `AGENTS.md`, `CLAUDE.md`, `usage-rules.md` or ST views.
5. **hv, verbatim: _hardcoded vanity metrics like test counts or whatever are STRICTLY FUCKING VERBOTEN._** No doc carries a hardcoded count of tests, rules, skills, subagents, files, rows or lines, and no size or "currently" line number the tool reports about itself. Name the verb that reports a figure, never the value. Any count found is DEAD and goes in the same pass. This outranks every other rule here.
6. **Records are exempt from rewriting.** That covers shipped CHANGELOG entries, `docs/releases/**`, `docs/v2/**`, `intent/history/**`, every `.history/**`, completed and cancelled ST docs, `examples/**`, `tests/fixtures/**`, `.archive/**` and `intent/eng/tpd/**`. The only check on them: where a reader could mistake one for current, give it a one-line historical banner.
7. **Keep the house style.** No manual wrap, `eg`, no em dashes in skill files, T-shirt sizes, 2-space indentation, and `prettier --write` before committing. Commit your own lane's paths only: `git add <paths> && git commit --only <paths>` in one call. A fix in another lane's file goes to that file's owner.
8. **Account for coverage.** When a lane is done, report to vc with every file in the lane and its disposition: clean, edited, deleted or exempt. A file missing from that list is a silent skip. The report is the trigger for vc's check.
9. **Nothing is pushed** until the audit is done and hv approves the push.

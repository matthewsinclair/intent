# ST0095: Git-style ids: threads, work packages and issues unique by construction

## Objective

Give every new steel thread, work package and issue an id that is unique by construction: derived from its creation event, minted on any branch, worktree or clone with no counter and no network, and never changed afterwards. Order every list by creation time. Keep every existing ordinal valid exactly as it is. Bring every door, view, document, skill, test and guard to the two forms, so that people and agents who share one repository through branches and merge requests never meet an id that means two things.

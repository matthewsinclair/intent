# WP-02: Linux assets on each tag's GitHub release, one writer per release object

## Objective

Each release tag's GitHub release carries the Linux assets beside the macOS ones, with one writer per release object: devbin's release core attaches them, and `bin/devbin release check` names no second writer.

## As built

- `linux-release.yml` runs on each `v*` tag and builds the Linux packages.
- `bin/devbin release attach vX.Y.Z` attaches them and writes `SHA256SUMS` over every asset the release carries; `bin/devbin release check` passes with `release.verbs: [check, attach]` declared in `bin/.devbin/config.yaml`.
- `bin/int macos publish` uploads the macOS assets and never writes the formula or the cask; `bin/int brew publish` alone writes both.
- `intent/docs/releasing.md` step 4 gives the order.

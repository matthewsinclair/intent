# WP-04: Slots: a generic pool, ask, grant, start, release protocol on the estate, records beside the status records, capacity enforced by the tool, policy with the controlling Claude

## Objective

A generic slot protocol on the estate: a controller session opens a named pool with a capacity, other sessions ask for a slot in it, the controller grants, denies or revokes, the holder starts and releases, and a grant over capacity is refused by the tool. The records live beside the status records under `~/.local/state/intent/estate/slots/<pool>/`, each request a directory whose files are written one each by the party that acts, so the state is the fold of the files and one writer per file holds. `slots wait` lets a requester block for the answer, and the UserPromptSubmit hook names pending asks to a controlling session. The page and the TUI show every pool, its queue and its holders, and each session's row shows the slots it holds. Policy beyond capacity stays with the controlling Claude.

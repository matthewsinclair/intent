# WP-17: The structured query door: intent search --sql, read-only over the published schema

## Objective

Give the CLI and the MCP tool a read-only structured query door, `intent search --sql <statement>`, over the store's published schema, so an agent or an operator can ask a precise question that joins the model and the index without a verb existing for it.

Design: design.md, the structured query door. One statement, a second connection opened read-only with query_only set and an authorizer permitting reads alone; a write, a second statement or a state-changing pragma is refused with the remedy naming the contract. Rows carry the schema version; `--json` is the MCP tool's envelope; `--limit` reports both denominators. A bare query is text and nothing is auto-detected. Independent of every other package; the overlap with the daemon's GraphQL face is named in the design as a decision for hv.

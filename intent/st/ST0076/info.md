# ST0076: A typed symbol index for Rust and Elixir: kinds, containers, qualified references and resolved references

## Objective

Make Intent's source index answer typed questions for Rust and Elixir: what kind a definition is and what it belongs to, where source names it with its qualifier, and, from each language's own toolchain, which definition a reference actually resolves to. Every answer says which of those three levels produced it.

## Context

ST0069 built the index's structural tier on each grammar's tags query and stored only def or ref, a name and a span. hv drove it on 2026-09-16 and ruled that it has to give typed, semantic-aware search over source, not something little better than grep, with Rust and Elixir required and Swift not. The measurements behind the ruling, the three levels and the work packages are in design.md. Issue 0429 (references inside macros, type uses, duplicate definitions) is descoped into this thread.

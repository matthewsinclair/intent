# WP-06: Elixir resolved references through the compiler's tracer, on an explicit verb

## Objective

_(not yet written)_

## Measured first (dc, 2026-09-17)

On a scratch copy of Laksa (Elixir 1.20.4, OTP 29, 537 `.ex` files; source, `deps/` with their `.git` directories, and `_build/dev` copied; the live estate untouched). The tracer was a module loaded with `elixir -r` and passed as `mix compile --tracer`, writing one row per event.

- **A full forced compile** took 69 s, exited 0 and recompiled no dependency. It produced 383,641 events (40 MB): `remote_function` 195,535, `alias_reference` 70,754, `remote_macro` 53,840, `imported_macro` 22,549, `require` 10,423, `import` 8,236, `local_function` 6,475, `imported_function` 5,441, then `alias_expansion`, `struct_expansion`, `alias`, `on_module`, `defmodule`, `start` and `stop` (537 each), `imported_quoted` and `compile_env`.
- **Most events are compiler expansion, not written references.** The top `remote_function` targets are `:erlang` 45,644, `Module` 39,458, `:elixir_def` 18,758 and `:elixir_quote` 9,752, generated by `use Ash.Resource` and similar and attributed to the `use` line. No field this first tracer recorded separated written from expanded; the compiler's own `:column` does (below). 21,664 rows are exact duplicates, 10,718 have no line, and 19 "files" are not project files (`@builtin`, `@component`, `@plugs`, `@prototype_schema`, and paths inside Elixir's own `lib/`).
- **The module distinction exists.** `get` arrives as `Access.get/2` 1,822, `Process.get/2` 852, `Map.get/2` 428, `Map.get/3` 313 and `Keyword.get/3` 254.
- **A tracer that raises aborts the project's compile.** The first tracer did, on the bare-atom events `:start` and `:stop`.
- **An incremental compile sees only what it recompiles.** Mix digests content, so `touch` alone compiled nothing and traced 0 events. Restoring a changed file compiled that 1 file and traced 90 events.
- **A failed compile leaves a plausible partial trace.** A forced full compile with one leaf file broken exited 1 after 16 s, with a `MismatchedDelimiterError` naming file, line and column. By then it had traced 244,414 events from 340 of 537 files, with 340 `:start` and 263 `:stop`. The gap between the 69 s and 16 s runs is unexplained on this host's load, so no timing claim is made beyond tens of seconds.
- **A written reference carries a column and an expansion does not** (dc, on a probe Mix project, Elixir 1.20.4 / OTP 29). Every written kind carried `:column` in its meta: remote, imported and local calls, remote and local captures, pipe targets, `__MODULE__` calls, the directives and module references. Generated events carried none: a written `to_string(total)` traced `Kernel.to_string/1` with a column and its expansion `String.Chars.to_string/1` without one, on the same line under the same name, so the join alone would have stored both. A syntax error fails before any `:start`, and an undefined function runs from `:start` to `:stop` and still exits 1, so the exit status is what names a failed compile.

## Rulings (vc, under the pen, 2026-09-17)

1. **A resolved row always resolves a written reference.** Level 3 never adds a reference that level 2's syntax does not have. It joins a tracer event to the WP-03 syntax reference in the same project file, on the same line, with the same name, and records on that row the module, name and arity the compiler resolved. An event with no matching written reference is compiler expansion and is not stored as a reference. The written `use Ash.Resource` is itself a reference and resolves to that module. Events with no line, and events from files outside the project, are dropped, and duplicates collapse onto the one row. **Nothing is dropped silently:** `intent index status` counts events matched, expanded-unmatched and dropped per language, so a join that stopped matching shows. WP-05 applies the same join to SCIP occurrences, so both languages mean one thing by level 3. **Expansion is kept out twice** (vc decision 27): the tracer records only call and module-reference events, and a call or module event whose meta carries no column is counted as `expansion` and never joined, because a macro's expansion can share the written line and name. A trace whose reference events carry no column at all fails the run. The test cannot see a macro that reuses a written node's meta for a call it generates, and that call is treated as written.
2. **The tracer never raises.** It catches everything around each event. A tracer fault is a failed run under 3, never an aborted project compile.
3. **A failed run stores nothing.** On a non-zero exit, or any file with `:start` and no `:stop`, nothing from that run is stored, and the envelope names the failure (file, line, message) beside the syntactic answer. Earlier good level-3 rows are kept, each carrying the content hash of its file at trace time. A file whose bytes have changed since then answers with its level-3 rows marked stale, never as current.
4. **Stored per file, replaced per file, in a build of Intent's own.** A run replaces exactly the files it compiled from `:start` to `:stop` whose bytes hashed the same before the compile and after it. The compile builds into Intent's own cache under `intent/.cache/resolve/elixir/<env>`, seeded from the project's `_build/<env>/lib` with its relative symlinks re-pointed, and re-seeded when `mix.lock` differs from the hash kept beside the seed. A run that seeds or re-seeds forces the compile, the first run and `--full` force it, and every other run is incremental. The project's `_build` is never written. It reads a Mix project at the project root only, and a project with no `mix.exs` there is not applicable. It runs on an explicit verb only, never from intentd. _This ruling first had the compile run in the project's own `_build`; vc replaced it at 06e046a89, in AC-06.1's text, after dc measured a shared build missing a file the user had compiled._
5. **Proof, in Laksa:** the callers of `Map.get/2`, without `Access.get/2`, `Process.get/2` or `Keyword.get/3`. The design's Proof section is edited to match after WP-01's vocabulary lands.

# WP-06: Elixir resolved references through the compiler's tracer, on an explicit verb

## Objective

_(not yet written)_

## Measured first (dc, 2026-09-17)

On a scratch copy of Laksa (Elixir 1.20.4, OTP 29, 537 `.ex` files; source, `deps/` with their `.git` directories, and `_build/dev` copied; the live estate untouched). The tracer was a module loaded with `elixir -r` and passed as `mix compile --tracer`, writing one row per event.

- **A full forced compile** took 69 s, exited 0 and recompiled no dependency. It produced 383,641 events (40 MB): `remote_function` 195,535, `alias_reference` 70,754, `remote_macro` 53,840, `imported_macro` 22,549, `require` 10,423, `import` 8,236, `local_function` 6,475, `imported_function` 5,441, then `alias_expansion`, `struct_expansion`, `alias`, `on_module`, `defmodule`, `start` and `stop` (537 each), `imported_quoted` and `compile_env`.
- **Most events are compiler expansion, not written references.** The top `remote_function` targets are `:erlang` 45,644, `Module` 39,458, `:elixir_def` 18,758 and `:elixir_quote` 9,752, generated by `use Ash.Resource` and similar and attributed to the `use` line. A column does not separate written from expanded. 21,664 rows are exact duplicates, 10,718 have no line, and 19 "files" are not project files (`@builtin`, `@component`, `@plugs`, `@prototype_schema`, and paths inside Elixir's own `lib/`).
- **The module distinction exists.** `get` arrives as `Access.get/2` 1,822, `Process.get/2` 852, `Map.get/2` 428, `Map.get/3` 313 and `Keyword.get/3` 254.
- **A tracer that raises aborts the project's compile.** The first tracer did, on the bare-atom events `:start` and `:stop`.
- **An incremental compile sees only what it recompiles.** Mix digests content, so `touch` alone compiled nothing and traced 0 events. Restoring a changed file compiled that 1 file and traced 90 events.
- **A failed compile leaves a plausible partial trace.** A forced full compile with one leaf file broken exited 1 after 16 s, with a `MismatchedDelimiterError` naming file, line and column. By then it had traced 244,414 events from 340 of 537 files, with 340 `:start` and 263 `:stop`. The gap between the 69 s and 16 s runs is unexplained on this host's load, so no timing claim is made beyond tens of seconds.

## Rulings (vc, under the pen, 2026-09-17)

1. **A resolved row always resolves a written reference.** Level 3 never adds a reference that level 2's syntax does not have. It joins a tracer event to the WP-03 syntax reference in the same project file, on the same line, with the same name, and records on that row the module, name and arity the compiler resolved. An event with no matching written reference is compiler expansion and is not stored as a reference. The written `use Ash.Resource` is itself a reference and resolves to that module. Events with no line, and events from files outside the project, are dropped, and duplicates collapse onto the one row. **Nothing is dropped silently:** `intent index status` counts events matched, expanded-unmatched and dropped per language, so a join that stopped matching shows. WP-05 applies the same join to SCIP occurrences, so both languages mean one thing by level 3.
2. **The tracer never raises.** It catches everything around each event. A tracer fault is a failed run under 3, never an aborted project compile.
3. **A failed run stores nothing.** On a non-zero exit, or any file with `:start` and no `:stop`, nothing from that run is stored, and the envelope names the failure (file, line, message) beside the syntactic answer. Earlier good level-3 rows are kept, each carrying the content hash of its file at trace time. A file whose bytes have changed since then answers with its level-3 rows marked stale, never as current.
4. **Stored per file, replaced per file.** A run replaces exactly the files it compiled from `:start` to `:stop`. The verb runs `mix compile` in the project's own environment and does not force. `--full` forces, and its help says a forced compile rebuilds the project's own `_build`. It runs on an explicit verb only, never from intentd.
5. **Proof, in Laksa:** the callers of `Map.get/2`, without `Access.get/2`, `Process.get/2` or `Keyword.get/3`. The design's Proof section is edited to match after WP-01's vocabulary lands.

# ST0087 WP-05: AC-05.3, devbin's doctor and upgrade in each of its trees

Recorded on rhadamanth by dc, from transcripts written by plain redirection, with no pty and stdin from `/dev/null`. Each leg ran in its own login shell, started as `env -i HOME USER LOGNAME SHELL=/bin/zsh TERM=dumb /bin/zsh -l -c`, so nothing else from the session that ran it reached the leg. In each transcript a line beginning `$ ` is the command, the `rc=` line after it is its exit code, and a `VERDICT` line is the script's reading of what came before it. Paths into other estates on this machine name them as `[another estate]`. The scripts are banked under `refs/bank/dc/0087-05/`.

## What the legs show

AC-05.3 asks that, in each of devbin's trees, `bin/devbin doctor` name the install devbin's switch chose and why, and that `bin/devbin upgrade` read that install. Each leg ran in a fresh `git clone --local` of this checkout at main's HEAD, made outside `~/Devel` because upgrade writes the vendored runtime. Every clone vendors devbin 0.1.15 (`4efb6e173e70`) and was clean before its leg.

- **brew**, with no link: doctor names `install: devbin 0.1.15 (brew, 4efb6e173e70), named by HOMEBREW_PREFIX's opt/devbin, since no DEVBIN_INSTALL_PREFIX or link names one`, and upgrade prints `Upgrading from /opt/homebrew/opt/devbin/libexec (devbin 0.1.15)` and finds the clone already up to date.
- **opt**, with the link at `/Users/matts/Devel/opt/devbin`: doctor names `install: devbin 0.1.14 (opt, 07f625a8c5e1), named by the link /Users/matts/.local/bin/devbin`, and upgrade prints `Upgrading from /Users/matts/Devel/opt/devbin (devbin 0.1.14)`.
- **dev**, with the link at `/Users/matts/Devel/prj/Devbin`: doctor names `install: devbin 0.1.15 (dev, 4d0376bc2907), named by the link /Users/matts/.local/bin/devbin`, and upgrade prints `Upgrading from /Users/matts/Devel/prj/Devbin (devbin 0.1.15)` and updates 4 files.

**The opt leg moved its clone backwards.** opt's devbin is 0.1.14, and this checkout vendors 0.1.15. upgrade printed `cannot tell whether this source is ahead of or BEHIND what is vendored here`, then updated 41 files and removed 3 without asking, so that clone ends at 0.1.14. AC-05.3 still holds on opt: doctor names the install and why, and upgrade reads that install. The backwards move is devbin's to fix.

**How opt and dev were switched.** devbin's own wrapper ran `devbin use <tree>`, read the switch back from a fresh login shell, ran the leg, and restored brew from a trap. Its log comes before each of those legs' transcripts, and each ends with `BREW RESTORED`. The wrapper ran from the same kind of bare login shell as the legs.

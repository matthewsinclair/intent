- AC-00.5 **R5 -- age format, both directions.** A store written by `intent` decrypts with the stock `age` binary, and a store written by stock `age` is read by `intent`. **This criterion is what the R5 deviation (crate rather than shelled binary) is answerable to** -- format compatibility is the thing R5's reasoning actually protects, so it is the thing asserted. -- satisfied: no (computed)

- AC-00.7 **R7 -- CI never requires the vault.** With `INTENT_VAULT_*` set and **no identity file present on the machine at all**, every read path succeeds. A vault that CI must unlock is a vault whose key is in CI. -- satisfied: no (computed)

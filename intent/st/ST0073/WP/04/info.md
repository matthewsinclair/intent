# WP-04: The fixture-home teardown leak

## Objective

Temporary fixture homes do not accumulate on /tmp across interrupted runs.

**A DIFFERENT LEAK WITH THE SAME ROOT CAUSE, AND IT IS SEPARATED HERE SO THE TWO FIXES ARE NOT CONFLATED.** 669 dirs / 75 MB measured 2026-09-10, none of them carrying a daemon state dir. A lifeline does not help a directory: a directory has no process to notice anything. The candidates are a fixed root that a suite-level entry point sweeps on START (which runs even when the previous run was killed), or `TempDir` under the OS temp root with the platform's own reaping. **Sweeping on start rather than on exit is the whole point** -- exit is the path that does not run.

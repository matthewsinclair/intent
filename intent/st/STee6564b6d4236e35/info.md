# STee6564b: Rethink /in-autopsy for the 3.5.x era of Intent

## Objective

`/in-autopsy` reads Claude Code session transcripts and reports where a session broke a rule that was in force. The skill dates from Intent v2.x, when one Claude worked with one person, and it looks only for a person's corrections and for banned words. In a 3.5.x project most of a session is tool calls and messages between seats, and the skill reads none of that as evidence. This thread rewrites the skill so that it reads a 3.5.x session: who wrote each entry, which `intent` verbs ran, what they printed and refused, what was committed, and which timestamps no clock gave. The skill reads the rules live from memory, the installed skills, the board, and the rule library, and it keeps no copy of them. Its report gives each finding with its evidence and the rule's source, and it goes to the mediator, who puts it to hv.

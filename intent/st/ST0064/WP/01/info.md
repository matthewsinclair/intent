# WP-01: Menubar app: control of intentd after Geodica's design -- no product logic, every control an intent verb, the daemon is the authority on the daemon

## Objective

**A Swift menubar app that shows `intentd`'s state, starts, stops and restarts it, tails its log in a terminal-styled console, holds preferences, and handles an `intent://` URL scheme -- holding NO product logic.** Every control is an `intent` / `intentd` verb it shells out to; every fact it displays comes from the daemon's status endpoint or the CLI; nothing in Swift knows a log format, a pidfile layout or a config schema. Geodica's app is the drop-in example, used more or less as-is with Intent-specific tweaks (hv, 2026-08-26).

## Intent-specific tweaks (the whole of the delta)

- **Status endpoint on `intentd`**: `GET /_status` returning JSON (pid, version, source commit, started_at, uptime, the projects it serves); the app polls it and derives running / degraded / stopped. The daemon is the authority on the daemon.
- **The tail-orphan trap, checked first**: if `intentd`'s log path is a pipeline behind a runtime, the verb takes its own process group down when its stdin closes, verified against SIGTERM, SIGINT and SIGKILL, BEFORE any console is built on it (`ps -A | grep tail` after a few ctrl-c's).
- **`intent://` URL scheme**: the handler resolves an `intent://` address through ST0057 WP-07's read resolution and opens it via `intent edit`.
- **Build pipeline as a devbin verb** (`int app build|run|test|install|uninstall|start|stop|status|icons`): xcodegen from `project.yml`; version, commit and source-tree hash passed as BUILD SETTINGS into Info.plist, never a generated Swift file; `status` compares the installed bundle's source-tree hash to the working tree; `run` execs the built binary rather than `open`; `lsappinfo`, not `pgrep`; `SYMROOT` / `OBJROOT` pinned so nothing lands on a synced tree.
- **PATH**: captured once from the login shell at launch and handed to every child; the CLI resolved through it with a Locate... override; nothing baked into the bundle.
- **Icon**: tinted only when the daemon is REACHABLE, template-rendered otherwise, orange for the transient; glyph drawn with gaps; rasterised with `rsvg-convert`.
- **Brand tokens**: Intent's own, not Geodica's ink / bone / accent.

# WP-07: The roster README is rendered from the profile and keeps the project's own block

## Objective

`intent/whiteboard/README.md` becomes a generated view with one writer. `intent wb init --apply` renders its upper part from the declared profiles and the store, and everything below a marker is the project's own and survives every re-render. A profile change reaches a project at its next `wb init`, and a project loses none of what it wrote.

## Builder and judge

cc builds this package and claims `ST0092/07` in the same chain as `intent wp start ST0092/07`. vc judges it and claims nothing.

## What was measured

26 of the 32 live boards have a roster README and 6 have none. 5 carry a verblock. Intent's own says, in its own text, that it has no single writer and that its rows lag. The function that keeps a preserved block across a re-render already exists, `carry_user_block` in `native/rust/crates/intentsvcs/src/canon.rs`, wired today to `CLAUDE.md` alone.

## What is built

- **One template** under `lib/templates/`, rendered through the token expander (`intentsvcs::rootfiles::substitute`): the declared profiles, the roster table with each seat's moniker, name, role, who drives it and remit, the route to hv, and the verb that prints the terms. The roster table arrives as one token filled from the store, so the expander needs no new block kind.
- **The preserved block.** A marker line, and below it the project's own prose, carried by `carry_user_block`. The function is reused, not copied.
- **The first render.** Over a README that has no marker, the whole existing file is carried below the marker and the verb says so. No hand-written line is lost, and the project prunes what the generated part now says.
- **Skew.** A hand edit above the marker is skew that `intent doctor` reports, as it is for a board's `wip.md`, and the next render restores it.
- **Nothing guessed.** Every generated line has a declared source, the profile or the store. This is the lesson of issue 0672, where a template wrote a language's default build lines into a contract and was wrong in most of the fleet. AC-07.4 states it as a test.

## What it is not

It is not where a session learns its seat: WP-06 is. It is not issue 0672's fix, which changes `lib/templates/llm/_AGENTS.md` and is ruled separately.

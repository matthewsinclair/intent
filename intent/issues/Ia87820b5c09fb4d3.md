## Problem

A project's CLAUDE.md, AGENTS.md or memory file can restate a rule that the global config already holds. The global rules are in the user config dir's CLAUDE.md, AGENTS.md and house-rules.md, which Molt links from Molt-matts. A restated rule is a second copy of one setting (Highlander). It drifts when the global copy changes.

## Ask

A check that flags each line in a project's CLAUDE.md, AGENTS.md or memory files that restates a global rule. It compares the project lines with the global files under the config dir that CLAUDE_CONFIG_DIR names.

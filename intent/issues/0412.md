`intent doctor` names remedies that cannot clear the findings it reports, and the pre-commit gate refuses on those findings, so a project can be wedged with no supported way out. Two instances wedged devbin's commit gate on 2026-09-16. Devbin letter L, driven by devbin/vc; devbin/dc read the source but did not re-drive either instance.

Found by devbin migrating its boards on Intent 3.0.3 (`d24487079`), sent through intent/vc on hv's routing, and ruled by hv on 2026-09-16 to be fixed in this release (hv decision 18). The full measurement record, with the instrument (`carry-map.sh`, driven red and green) and who measured what, is devbin `1824c75`, `intent/whiteboard/dc/.history/20260916/wb-upstream-defects-draft.md`.

1. **A closed issue's leftover view.** `intent/issues/0065.md` in devbin was a closed issue's view no longer declared in `.intentfiles`: `sync --to-disk` skipped it, doctor kept counting it, and `organize` refused to guess. devbin/vc removed the file by hand (recorded in devbin `5f0460e`).
2. **A registered-but-unmigrated board.** doctor called `vc/wip.md` "a generated view that differs from the model" (7546 bytes on disk against the 422 the empty row renders), named `sync --to-disk` as the remedy, and warned the remedy would discard a hand edit. It does neither: rebuilt in a scratch copy and driven, the remedy exits 0, `vc/wip.md` is byte-identical afterwards (same hash), and doctor reports the same finding again. The code says so at `facade.rs:7332` ("THE MARKDOWN BESIDE IT IS NOT TOUCHED"). It was among the 24 findings that refused the commit.

Related closed issues in the same class: 0199 (the canon-commit gate's remedy cannot unblock it), 0164 and 0165 (a remedy naming a destructive step), 0306 (doctor counting undeclared issue views). This is the class recurring through the whiteboard and the issue views.

Fix: doctor never names a remedy that cannot clear its finding, and never warns that a remedy discards what it leaves untouched. A registered-but-unmigrated board is reported as that, with `wb migrate` as its remedy; an undeclared leftover view has a remedy that removes or declares it.

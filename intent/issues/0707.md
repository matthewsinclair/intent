Main tracks the views of closed threads that `.intentfiles` no longer lists. doctor counts nothing. `intent sync` plans "views (reversible): write 0 view(s) and remove 3"; a hook, or a run without a terminal, leaves the step, and `--yes` removes the files.

The step that resolves a merge's view conflicts needs `--yes`, so every branch deletes the same files, and every merge request carries the same deletion until main does it once. Nothing says so.

Expected: `intent upgrade`, or doctor on a default run, names the views the manifest no longer declares and the one commit that removes them. What upgrade does is cc's; what doctor says is ic's.

No verb writes a thread's `related` links. `related` is readable as a descent and writable by nothing, so the only repair for a dangling or misdirected link is a hand edit of `intent/.canon/st/<ID>.json`, taken in by `intent sync --apply`'s ingest.

**Where it bit:** Lamplight, 2026-09-18. ST0340, ST0341 and ST0342 name ST0338, a thread adopted as ST0356 on 2026-08-21. The estate's own commit gate refuses every commit under `intent/` until the links are repaired, and no command can repair them.

**Driven on a fresh scratch project with the 3.0.3 pair at ba4c37b57:**

- `intent set intent:///threads/ST0001 related '<json list>'` refuses at exit 1 for every value, including `[]`: "`related` will not take that value: invalid type: string "...", expected a sequence". `set` hands the field a string, so the field is unwritable through it, whatever is typed.
- **The refusal's remedy names a door that does not exist:** "go to the door the refusal names: a lifecycle verb for a field a state machine owns, and the member's own address for a collection". There is no lifecycle verb for `related`, and a member address refuses: `intent:///threads/ST0001/related` and `intent:///threads/ST0001/related/ST0002` both answer "has trailing segments after a complete address". So the operator is sent round to nothing, the remedy-that-cannot-be-acted-on class.

**What a verb would need, two shapes:**

1. Repoint an entry: change its id and edit its note, eg ST0338 becomes ST0356 with the reason it was adopted.
2. Drop an entry.

`intent st renumber` already rewrites other threads' `related` references when an id moves (ST0078 P2). That covers a renumber, not an adoption or a link that was wrong from the start.

**Severity medium, not low: a refusal whose remedy names a door that does not exist is a stop with no exit on an estate whose gate is blocked, which is worse than a missing verb.** No fix in this line. Until there is a verb, the refusal's remedy should at least name the real repair (edit the canon file, then `intent sync --apply`) rather than a door that does not exist.

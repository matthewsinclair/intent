Raised by utilz-vc on hv's instruction, 2026-09-14, from Utilz.

## What happened

On 2026-09-14 utilz-vc ran `bin/devbin macos prepare --help` in Intent's tree, to learn what the command did without running it. The flag was dropped and `prepare` ran: it rebuilt Intent.app and re-signed the staged copy, and left the staged copy un-notarised. The published 3.0.3 was not affected.

Running another project's command to learn it was utilz-vc's mistake, and Utilz's `intent/restart.md` now carries the rule to read the source instead. This issue is about the shape that turned a request for help into a signing run.

## Why

`bin/.devbin/cmd/macos` answers help in one place only, the subcommand's position:

    case "${1:-}" in
      "" | -h | --help) usage; exit 0 ;;      # :2956
      ...
      prepare) cmd_prepare ;;                  # :2964

So `macos --help` prints the usage, but `macos prepare --help` matches `prepare)`, and that arm passes nothing on. `cmd_prepare` (`:1302`) takes no arguments and starts at once: `cmd_app_sign`, `cmd_app_notarize`, `cmd_stage`, `cmd_sign`, `cmd_notarize`, `cmd_checksum`.

It is not one arm. Derived from the case block, **16 of its 21 subcommand arms pass no arguments on**: `env`, `doctor`, `stage`, `sign`, `notarize`, `verify`, `checksum`, `prepare`, `store-creds`, `app-doctor`, `app-icons`, `app-run`, `app-test`, `app-install`, `app-sign` and `app-notarize`. Anything typed after one of them, `--help` included, is dropped without a word, and the subcommand runs.

The other five, `formula`, `publish`, `smoke`, `app-build` and `app-verify`, pass their arguments on. None of their bodies names `--help` or `-h`, so what each does when handed `--help` was not established here.

## What a fix has to give, none of it ruled

- `-h` or `--help` anywhere after `macos` prints help and exits 0, before any side effect.
- A subcommand that takes no arguments refuses one, and names it, rather than dropping it.
- The five that take arguments either answer `--help` or refuse it as not one of their arguments.

Severity high, because the flag people and agents type to learn a command is the flag that runs it here, and `prepare` rebuilds and signs release artefacts and submits them to Apple for notarisation.

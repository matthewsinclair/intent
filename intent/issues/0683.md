`bin/devbin prepush` (`bin/.devbin/cmd/prepush`), the pre-push gate, judges every push by the delivered pair's currency verdict. That includes a push that only deletes a remote ref, whose local sha on pre-push's stdin is all zeros. Such a push sends no commit, so the pair's currency says nothing about it. Yet it falls to the same verdict and can be refused. dc met this during the 3.3.0 cut.

When every line pre-push reads has an all-zero local sha, the gate should exempt the push, saying so in one `ok:` line. A mixed push is still judged whole. The frozen-remote check stays as it is, because deleting a ref on a frozen remote is still a write to it.

Found on the 3.3.0 cut. Filed, not built, on vc's word (2026-11-11).

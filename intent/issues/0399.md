hv, 2026-09-15: a thread or issue view in the explorer becomes a split view. The top half is the entity's fields, as now. Below a divider, the bottom half shows the contents of the field selected in the top half: read-only, pretty-printed as markdown, and scrollable. In hv's example, issue 0398's view shows its fields above and its `body` rendered below.

- TAB moves between the top half and the bottom half.
- In the bottom half, the arrows, Page Up/Down and Home/End scroll the contents.
- Enter edits the selected field from either half, exactly as Enter on the field does today: a single-line field edits in place, and a document field (a `prose` widget in `surface/forms.json`, such as a thread's objective or an issue's body) opens the full editor.

**AS BUILT, WHICH IS WHY hv REMEMBERED A SPLIT AND COULD NOT FIND ONE.** The list+detail split exists (e25760afd, with TAB crossing the panes in cbf4e2163; `tui-design.md` section 6): the body splits when the selected row carries detail, and the hint row then offers `TAB detail`. Only the rows of a thread's work package, criteria and test lists carry detail (`render.rs` `children_of`), so an issue's fields and a thread's own fields never split. The pane draws its rows one line each and clipped; `/help` lists the mode machine's edges, and TAB is a guard rather than an edge, so the page never names it; and `tui-design.md` records a field's contents in the pane, and markdown rendering, as not built.

**THE CHANGE, ON THAT MACHINERY:**

1. On a thread or issue view every row carries detail. A field's detail is its whole value. A collection row's (work packages, criteria, tests, documents) is its members, one line each, as its own list shows them, and Enter still opens the list.
2. The pane renders a field's value as markdown through a ratatui markdown component: styled headings, emphasis, inline code, highlighted code blocks, lists, quotes and tables, in the explorer's own colours. The list keeps one clipped line per row, as now.
3. A split body divides in half, replacing the take-what-it-needs sizing, so the pane does not jump as the cursor moves from a one-line field to a long one.
4. In a contents pane the motions scroll, and Enter acts on the top half's selected field.
5. `/help` names TAB and the pane keys, and `tui-design.md` section 6 is corrected forward in the same landing.

The component is any Rust crate with no Python dependency (hv, 2026-09-15), and hv drives the worktree's binary before anything lands.

On 2026-10-18 a node launch for one project ran in the wrong directory: `~/Dropbox/Repositories/Devel/<group>/<repo>`, the bare repository that the working copy at `~/Devel/prj/<group>/<repo>` pushes to as `local`. The two share a basename. Nothing in Intent objected:

- `intent init` (event 01M57GPQCJ7T5JV6GSKPSNW80T, 12:45:07Z) created a project inside the bare repository, writing AGENTS.md, CLAUDE.md, .gitignore, .prettierignore and an intent/ tree beside HEAD, config, objects and refs.
- `intent wb register dc` (event 01M57GPSE823KKPMZJQ9EP82CB, 12:45:09Z) registered a node in it.
- `intent claude start dc` found the new `intent/.config/config.json` through `find_project_root` in `intent/plugins/claude/bin/intent_claude_cwi`, changed into the bare repository and launched a Claude Code session there.

The session ran /in-session and a whiteboard pickup before anyone noticed. The project's dc removed the five stray items the same day; the repository's refs and objects were untouched, and git would have refused a commit there, having no work tree. The cost was a polluted remote and a node registered in a throwaway project, but every step was silent.

Repro: `git init --bare /tmp/x.git && cd /tmp/x.git && intent init` succeeds. Do not finish with `intent claude start`: it launches a real session.

Proposed fix, in as few places as possible:

1. `intent init` refuses when the target directory is a bare git repository or inside one (`git rev-parse --is-bare-repository` prints `true`), naming it and saying that a project belongs in a working copy.
2. The project-context gate refuses any command whose project root is a bare repository, so a project already initialised in one, as this one was, is inert.
3. `intent_claude_cwi` makes the same check after `find_project_root`, because it is a script outside the binary's gate.

Acceptance: in a fresh `git init --bare` directory, `intent init` exits 1 and writes nothing; in a bare repository holding an intent/ tree, `intent wb register` and `intent claude start <ws>` exit 1, the latter before launching anything.

Reported by a project's dc (DevX Claude), filed on hv's word.

## What

`lib/templates/.claude/scripts/post-tool-advisory.sh:68-75` decides which critic runs on an edited file from a `case` on the file's extension: `.ex` and `.exs` are elixir, `.rs` rust, `.swift` swift, `.lua` lua, `.sh`, `.bash` and `.zsh` shell, and anything else exits 0 with no critic run. The binary already has the one map, `lang_of` in `native/rust/crates/intentsvcs/src/index/corpus.rs:109`, which the index and search read.

The two agree today. A language added to `lang_of`, or a new extension for an existing language, is skipped by the hook without a word, because its `*) exit 0` arm cannot tell an extension nobody handles from one it was never told about.

## Expected

The hook takes a file's language from the binary instead of from its own table: `intent critic` derives it from `lang_of` for the path it is given (or a read verb answers it), so a file's language is decided in one place.

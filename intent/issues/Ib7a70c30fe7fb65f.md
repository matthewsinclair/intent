`gitstate::staged` and `gitstate::export_ignore_decided` ask `is_work_tree`, which reads a git that could not be asked as no work tree (`unwrap_or(false)`). So a git that refuses (dubious ownership, a damaged .git) answers "nothing staged" and "nothing decides export-ignore", against issue 0730's one answer.

Expected: both ask `work_tree`, the three-answer reader, so a git that refuses is a GitStateError the caller surfaces.

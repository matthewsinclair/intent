**A GREEN AT ROW ON A COMPLETED THREAD STAYS CONFORMING AFTER THE TEST IT CITES IS DELETED, AND NO SURFACE NAMES THE DRIFT.**

**Measured by gtools-vc on Intent 3.2.8, in a throwaway Gtools worktree, and relayed by devbin-vc on 2026-10-31.** Deleting the `tools/ci-state` block from Gtools' `test/gtools_release_test.exs` left AT08 reported green and conforming by `intent at lint` (9 of 9 rows), and `intent doctor` showed nothing at any scope. The cited file still exists, but the test that carried the row's literal id does not.

**The mechanism, read by intent-vc in Intent's tree at 609f3bc48.**

- `intent at lint` calls the same `contract_report` the close gate calls (`Facade::at_lint`, `native/rust/crates/intentsvcs/src/facade.rs`), so the lint and the gate agree by construction, and both pass this row.
- `contract_report` exempts a Completed thread from L3, the literal-id rule: `let completed = thread.status == ThreadStatus::Completed;` (`native/rust/crates/intentsvcs/src/contract.rs:814`), and the `carries_id` check runs only `if !completed` (`contract.rs:847`). L2, the check that the cited file exists, still runs after close.
- Gtools' AT08 is ST0012's (`test/gtools_release_test.exs:191` on Gtools' main: `# AT08 (ST0012) covers AC07: ...`), and ST0012 has been Completed since 2026-09-25. The exemption is what passes the row.

**Why this is a gap and not the exemption doing its job.** The exemption's own comment (`contract.rs:812-813`) gives its reason: "retrofitting id labels into a completed thread's tests is archaeology". That covers tests written before the label rule existed. Without saying so, it also covers a test deleted after the thread closed: the row stays green, every surface reads it as conforming, and nothing names the drift. Deleting the whole file is caught by L2, but deleting the test inside a file that survives is not.

**Related.** Issue 0267 (closed 2026-09-11) named this same exemption as its second edge, "silently exempt after close". The code at HEAD still exempts it, for the reason above.

**What a fix has to decide**, which is the reporter's to rule: whether a completed thread's green rows keep a check of their own (for example, a row whose cited file carried its id when the thread closed and no longer does), or whether doctor reports the drift without reopening the thread.

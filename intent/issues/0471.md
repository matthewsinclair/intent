`bin/devbin canon`'s header says it exits 1 on divergence and 2 only if its controls fail (`bin/.devbin/cmd/canon`, "Exit 1 on divergence so a fold can key on it; exit 2 only if the controls fail"). Every control failure goes through `die`, which exits 1 (`bin/.devbin/lib/helpers`), so a broken instrument exits exactly as a real divergence does, which is the conflation the exit-2 split exists to prevent.

Fix: exit 2 from the control failures. XS. Found in dc's doc sweep of 2026-09-18 (finding C-22).

`lib/templates/hooks/pre-commit-guards.sh` decides applicability with a PATH test, then reads exactly two answers from the guard it dispatched: exit 0, counted in `RAN`, and non-zero, which sets `BLOCKED`. There is no third answer.

**The class already exists and a dispatched guard cannot reach it.** The runner keeps a `SKIPPED` counter, incremented where a roster row's `applies-when` names a path the tree does not carry, and the summary prints `guards: N ran, M skipped (not applicable)`. Both dispatch loops -- the canon roster's and the project-declared one (`P_RAN` / `P_SKIPPED`) -- count a guard that ran as RAN whatever that guard decided about itself.

**Seen, 2026-09-22, on issue 0505.** `staged-format-guard.sh`'s applicability is not a path: every Intent project carries `intent/.config/config.json`, and what decides the guard is whether that file DECLARES formatters. So the roster's path test can only say yes; the guard runs, finds nothing declared, and exits 0, which the summary counts among the guards that ran and passed. The guard therefore prints its own line -- `not applicable -- <config> declares no formatters.` -- and that line is prose: nothing carries it into the summary, into `--list-guards`, or into any tally a reader or a script reads.

**Cost:** the summary overstates what was checked, which is 0505's own sentence pointed at the runner -- a check that did not run is indistinguishable from a check that passed. And every later guard whose applicability is a DECLARATION rather than a path inherits the same workaround, each in its own words.

**Expected:** the runner learns a not-applicable answer. An exit code is free (1 is BLOCKED and 2 is the shell's own error, so 3), counted in the existing `SKIPPED` class in both loops, carried into the summary and named in `--list-guards`'s state column.

**Not in 0505, and why (vc, 2026-09-22):** this changes the one file that dispatches every guard in every estate on this machine, read live from the install, so it is live on save for all of them; it owes its own arms and its own judging rather than riding a guard's bank.

**0505's printed line is the interim.** When this lands, `staged-format-guard.sh` answers with the not-applicable code and its printed line goes -- or the line outlives its reason.

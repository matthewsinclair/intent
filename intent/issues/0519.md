The rule for what a board may claim is stated in prose in TWO independent places, in different words, and a widening has to remember to change both.

`facade.rs`, the remedy for `WbClaimMalformed`, which `wb claim` raises on a value typed at the verb:

    claim a thread as `ST0000`, a work package as `ST0000/01`, or an issue as `ISSUE:0000` -- the spelling `.intentfiles` already uses. A claim names what the board can point at, so free text here would be a claim nothing can resolve

`wbmigrate.rs`, the `reason` on an `Uncarried` line, which `wb migrate` raises on a value read off a hand-authored board's header:

    not a claim address: `wb claim` takes a thread as `ST0000`, a work package as `ST0000/01`, or an issue as `ISSUE:0000`

**THE VALIDATOR IS ALREADY ONE HOME AND THAT IS THE POINT.** `model::is_claim_address` is documented as "ONE HOME FOR EVERY DOOR THAT ADMITS A CLAIM", and both doors do call it -- so the two doors cannot disagree about what they ACCEPT. What they can disagree about is what they SAY, and the sentence is what a user acts on.

**MEASURED, RATHER THAN PREDICTED: BOTH WERE STALE TOGETHER UNTIL 0511.** Each read "a thread as `ST0000` or a work package as `ST0000/01`" and each had to be found and edited separately when hv's decision 29 admitted the issue form. They happened to be found because 0511's author went looking for every home; nothing in either file points at the other, and no test compares them.

**AND THE THIRD HOME IS NOT PROSE AND IS NOT A DUPLICATE**, so it is named here to bound the issue rather than to widen it: `surface/dispatch-table.json`'s `wb claim` row carries `help`, `when_to_use` and the arg type, and generates CLI help and the MCP tool schema. That one is read BEFORE any refusal and is a contract rather than a message, so it belongs where it is.

SIZE: XS to state the two together, S if the remedy is to derive both from one declaration. The shape the estate already uses for a legitimate second copy is a test holding the two identical -- `CLAIM_ISSUE_PREFIX` against `Sigil::Issue::as_str()` in `model.rs` is an example landed in the same change -- rather than prose discipline.

PROVENANCE. Found by cc on 2026-09-22 while landing 0511, flagged to vc rather than folded in, and filed on vc's ruling that two independent sentences stating one rule is its own question and not a rider on the widening that exposed it.

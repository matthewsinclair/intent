## What

An agent that reads prompt-shaped text which is not live can act on it as if it were an instruction. Old versions of skills in git history are the case found: a skill as it stood in an earlier commit (from `git log -p`, `git show`, a diff or a blame) reads like a skill, and an LLM that ingests it can follow it, even though the current skill says something else or the skill no longer exists. Nothing is attacking the agent. The text was written by us, for an agent, and only its tense is wrong. Call it passive prompt injection.

Intent is more exposed to this than most projects, because so much of what it stores and ships is prompts: skills, critic rule libraries (`rules/<lang>/`, the Detection heuristics), agent files, `AGENTS.md` and `CLAUDE.md` templates, usage rules, whiteboard messages and archives, `intent/history/`, autopsy inputs (session transcripts), and the superseded versions of all of these in git. Any agent that greps, diffs, audits or autopsies the repo reads instruction-shaped text with no marker of whether it is current.

## Where it bites

- An agent reviewing a diff or a commit range reads the removed lines of a skill or rule and applies them.
- A critic or autopsy that reads history, transcripts or old rule versions treats a retired rule as in force.
- A rule that was deliberately reversed (the skills carry several "this line read X until <date>" notes) comes back through its old text.
- Archived whiteboard messages or `history/` docs addressed to "you" are read as addressed to the current reader.
- Downstream projects that install Intent's skills and rules inherit the same exposure through their own git history.

## Expected

Prompt text that Intent stores or ships is only ever acted on when it is live, and every other copy says so where the agent reads it. Directions to triage:

- An audit of every Intent surface that feeds prompt text to an agent, live or historical, and which of them can surface stale copies.
- A convention for non-live prompt text (history, archives, quoted old rules, examples), eg a framing marker an agent is told to treat as data, not instruction.
- Guidance in the skills and agent files that read history, diffs, transcripts or archives (autopsy, review, critics, whiteboard) that what they read there is evidence, not instruction.
- Rule-change notes that quote the old rule in a form that cannot be mistaken for the rule.
- Tests or fixtures that put a stale instruction in front of a critic or skill and check it is not followed.

The daemon's second watch registration, added for the index under ST0069 WP-18 (25ca2e9ac), watches the project ROOT recursively (`native/rust/crates/intentd/src/watch.rs:154-164`); at 3.0.1 only `intent/` was recursive (watch.rs:127). The registration goes through notify-debouncer-full 0.7.0, whose `RecommendedCache` on macOS is `FileIdMap` (cache.rs:64-65). That cache's `add_path` is a `WalkDir` with `follow_links(true)` and a `stat` per entry (file_id_map.rs:39-53), and it runs over the whole root at `watch()` (lib.rs:589), over the path on every Create event and every event on an uncached path (lib.rs:298-300, 335-337), and over ALL roots on any FSEvents MustScanSubDirs, user-dropped or kernel-dropped flag (notify 8.2.0 fsevent.rs:116-121, then lib.rs:282-283 `cache.rescan`). It runs inside the watcher callback under the debouncer lock (lib.rs:692-700), on the `notify-rs fsevents loop` thread. The ignore rules that bound the index's corpus apply to events after the fact; the cache walk does not read them, so on a tree with build directories it stats every entry under `native/rust/target/` and every worktree's target dir, and a burst of writes (a cargo build, a store mid-index) is exactly what makes FSEvents drop and flag a rescan.

Measured on the live daemon (pid 58837, e70c3528a) at 2026-09-13 15:10:52Z: the second `notify-rs fsevents loop` thread had 0:29.43 user and 0:03.16 system of CPU (`ps -M` row 23, mapped to the thread by a `sample` taken while the daemon was cool); the first had 0:00.52 and 0:00.07. That is the walk's cost so far on this tree, bounded and separate from issue 0354's spin (which is the store thread, 24 minutes at the same moment). cc's reading (reading-only, 2026-09-13) attributes the cost; the per-rescan cost has not been measured on its own, and `follow_links(true)` on a tree that carries symlinks has not been driven.

Remedy candidates, none ruled: a debouncer without the `FileIdMap` cache (`NoCache`; renames then arrive as Remove plus Create, which an index reconcile keyed on content may not need), a cache whose walk honours the corpus's ignore rules, or a registration that does not cover build directories. Per-directory registration was rejected on 2026-09-12 (decision 9). Fix shape to be ruled with cc; not the cut's hold.

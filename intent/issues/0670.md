**AN AT ROW PASSES THE CONTRACT WHEN THE FILE IT CITES CARRIES THE SAME-NUMBERED ID ON ANOTHER THREAD'S ARM, AS LONG AS THAT LINE NAMES NO THREAD.** So a row can read green with no id over its own arm. 0267 scoped the check to the thread and kept the bare id line green on purpose; this is the case that choice lets through.

**The mechanism, read by intent-vc in Intent's tree at a06ac2cd1.**

- The contract calls `refs.carries_id(path, &t.id, &thread.id)` for each row (`native/rust/crates/intentsvcs/src/contract.rs:848`).
- `RepoFiles::carries_id` (`contract.rs:344-367`) collects every line that contains the id and answers `Yes` when any of them does not name another thread. `names_another_thread` (`contract.rs:262-265`) is false for a line that names no thread at all, so a bare `# AT-3.5` counts for every thread whose row cites the file.
- That shape is 0267's, chosen on purpose. Its comment (`contract.rs:336-343`) says a line naming no thread "carries no evidence of belonging elsewhere", and that requiring a thread-qualified id would have reddened 160 of the 196 rows the check applied to. In a file that two threads share, the bare line does belong elsewhere, and nothing on the line can say so.
- Read, not driven: the match is `line.contains(at_id)` (`contract.rs:348`), so a line carrying only `AT-3.50` would also count for `AT-3.5`.

**Why it matters.** The literal id is the coverage mechanism, not a naming convention (`contract.rs:307-313`): it is how the gate knows the cited file tests this criterion. Here it reports coverage the cited arm does not have. In ST0011, the 21 rows that fail are honest, and the one that passes is the one whose own arm carries no id.

**What a fix has to decide**, which is the reporter's to rule.

- devbin-vc's recommendation, which intent-vc shares: the check looks for the id over the thread's own arm, or the row cites the arm's line (eg `tests/unit/releasestatus.bats:161`), so the gate reads the id where the arm is.
- Either way, a bare line on another thread's arm stops counting, which is the case 0267's comment set aside. Measuring how many rows that reddens across the estate comes first, as it did for 0267.

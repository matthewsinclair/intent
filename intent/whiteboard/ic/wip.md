## Watch-outs — mechanisms only

**A lesson that now has a guard is not here; the guard is the durable form.**

1. **A TRUE RESULT FROM AN INSTRUMENT THAT COULD NOT HAVE ANSWERED DIFFERENTLY.** The dominant class, in four shapes I have hit: a mutation run that measured nothing because the staged tree did not compile, so every "kill" was a compile error; **a mutation whose string replacement matched nothing, which is indistinguishable from a surviving mutant**; a probe whose `lead` still pointed at the old positional, so it refused about a question nobody asked and stayed green; and a harness with `lead` and no `trail` because every declared slot had always been its row's last positional. **Assert the mutation APPLIED, and assert the baseline RAN, before believing either.**
2. **EVERY MEASUREMENT ASSERTS ITS OWN PRECONDITIONS FIRST — HEAD, cleanliness, and the presence of what it needs.** `git checkout --detach` ABORTS on a dirty file and says `Aborting`; I read the compile error below it and not the refusal above it, and measured the wrong commit. **A baseline taken at one HEAD is void at another.** A binary is asserted to carry the change before it is driven.
3. **A GREP FOR A CALL SITE CANNOT FIND ONE THAT TAKES A VARIABLE.** Deleting `flag()`: three enumerators found 3, 12 and 17; **the compiler found 24**, because `flag(m, other)` matches no literal pattern and never could. **Assert the END STATE, never a count**, and let the build enumerate where it can.
4. **A HELPER THAT READS A DECLARED THING THROUGH A TYPE ASSUMPTION RETURNS A PLAUSIBLE FALSE, AND `.ok()` IS WHERE IT HAPPENS.** clap stores a `bool` for `SetTrue` and only that, so a valued flag was a mismatch the `.ok()` discarded and the flag read as ABSENT — given, parsed, invisible. **The fallback was a reasonable thing for the command to do, so it read as a design decision.** `get_flag` is the LOUD twin: same clap call, a panic instead of a lie. **And removing a swallow means finding out what it was swallowing** — this one also carried `--force` legitimately absent on some rows, my replacement crashed 47 tests, and **the warning was in the same file and I had quoted it into the fix.**
5. **A DECLARATION KEY IS A PROMISE THAT CODE READS IT.** If no type deserializes it, the behaviour is absent or hand-written to match by coincidence, **and the coincidence never surfaces because agreement looks exactly like correctness.** `INHERITED_UNREAD` is a RATCHET ON ADDITIONS, not an excuse list: the fix for a declared-and-unread flag is the arm.
6. **DERIVE THE SECOND VALUE OUT OF EXISTENCE RATHER THAN TESTING THAT THE TWO AGREE** (vc's ruling, twice). A test comparing two authored values can only fire AFTER someone writes the second one — it catches the divergence, it does not prevent it. The ellipsis derives from `arity`; the undo derives from `Step::ORDER`; v2-ness derives from `v2_source`. **A grep-shaped guard is right only where there is nothing to derive**, as with a shape a future author can retype from scratch.
7. **`gen_dispatch_table.sh` REFUSES ON EVERY DERIVED COUNT WITH A SECOND HOME AND HAS NEVER BEEN WRONG** — twelve refusals across two sessions: new-surface counts, the `legal_pairs` census, unclassified keys, an orphan invariant, an invariant's `target` shape, a bent `recoverability` label, and populations in the wrong ORDER. **`populations` is corpus order, never sorted.** Let it check you; do not pre-empt it. **Its own sentence is the rule: `do NOT adjust the label to make the number come out`.**
8. **THE SHARED WORKTREE MAKES MID-EDIT STATE VISIBLE TO EVERY PEER'S BUILD.** The dispatch table is COMPILED IN, so a malformed one is not a bug a user could hit — **it is a binary that will not start, for everyone.** Three routes to that in one night: an absent `subcommand` arg, a literal `values: null` (**`jq` prints `null` for an ABSENT key and I read the print as the value**), and a mutator roster naming a row that stopped being a mutator. **Shortest possible edit window, and announce at both ends.**
9. **THE COMMIT GATE READS THE INDEX, SO A PEER'S STAGED INTERMEDIATE BLOCKS EVERY NODE** — and `--only` is the very protocol that causes it, because it builds its tree from HEAD plus the named paths. **Measure whether the block is yours before asking anyone to move.** **NEVER `--no-verify`**: it takes the clock and header guards with it.
10. **AN ATTACHMENT EDIT IS A SUITE-WIDE EVENT.** `sync --to-store` has no unit narrower than a THREAD, so a canon sync writes whatever is dirty. **Nothing is lost and that is not the point — the bytes move under someone else's name. Ask; do not sweep.** And a hand-edit to a GENERATED view is destroyed silently by the next sync, in files whose own footer says so.
11. **`cargo fmt --all` IS THE UNGUARDED TWIN OF A GUARDED DOOR, WITH THE SHORTER SPELLING.** I reformatted two peers' files with it. **`--check` first, always**, and format only your own paths. Formatters now REFUSE rather than write (vc's ruling), so a rustfmt-clean tree matters at commit time rather than after it.
12. **A DETACHED WORKTREE GETS ITS OWN `CARGO_TARGET_DIR`, AND THAT DIRECTORY DIES WITH IT.** `testkit` bakes `CARGO_MANIFEST_DIR` at COMPILE time, so an rlib built in a worktree later deleted panics with `a Cargo.toml declaring [workspace] above this crate` — **pointing at a file that is entirely innocent.** That panic means you measured a poisoned artefact, not a regression. **And do not build at all while another node is running the suite.**

An apostrophe in a single-quoted string is a hard syntax error; `${=v}` splits and bare `$v` does not; `while read -r st path` DESTROYS `$PATH`; an unmatched glob aborts the whole command. **Never `$?` after a pipe** — five instances now. **Use a quoted heredoc for anything carrying prose.**

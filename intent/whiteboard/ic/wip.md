Never enumerate remotes through `head`. **INSTANCE 2026-08-17, with this rule already on this board: a probe loop doing `"$B" $a` produced six clean rows saying `intent --version` refuses unknown arguments -- the exact opposite of the truth.** `--version --zzz` arrived as ONE argument and clap rejected the whole token. **The giveaway was in the output the whole time: the error quoted both words inside one pair of quotes.** Probe from a bash file with real argument vectors for anything whose result gets written down.
- **`path` IS A SPECIAL ARRAY IN zsh, TIED TO `$PATH`, AND ASSIGNING TO IT DESTROYS THE SHELL.** An audit loop of mine did `read -r path disp arity flagjson`, setting `PATH` to `st new`; every subshell after printed `command not found: jq` and reported all 60 rows unparseable. **The bash script it was auditing uses `path` too and is FINE.** **When an ad-hoc harness reports a wall of findings, suspect the harness first.**

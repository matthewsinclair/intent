# A hub

This project is a hub: its supervisor coordinates other projects, each with its own Team and its own vc. The supervisor is this hub's mediator, so on this whiteboard hv is reached through the supervisor. On each project it coordinates, the supervisor holds that project's sv seat, which brings findings and briefs to that project's vc and builds nothing.

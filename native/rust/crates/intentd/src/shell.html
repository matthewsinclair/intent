The Intent daemon is running, and this port is answering.


  


  

    
Version
{{VERSION}}

    
Serving
this shell page, the mark, and POST /op

    
Also on
the unix socket, and this same port for framed clients

  


  


  

    This page is the shell and nothing more. The daemon emits JSON only —
    it renders no view of your estate, deliberately, because the same answers have to serve a
    browser, a terminal and a menubar app, and a face that returned HTML to one of them would
    owe the other two a second contract. The interface that goes here is built on
    POST /op, which answers the identical call the unix socket answers.
  


  

    /op requires the secret this run published, so that a page you did not open
    cannot read your estate over loopback:
  


  

    
    
curl -s http://127.0.0.1:$PORT/op \
  -H "Authorization: Bearer $(cat ~/.local/state/intent/run/intentd.token)" \
  -d '{"root":"'"$PWD"'","op":"registry"}'

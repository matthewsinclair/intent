# ARCHITECTURE.md

How [[PROJECT_NAME]] is shaped, and why.

Nothing can generate this document for you. An index of the source tree can tell a reader what exists and where. Only this document can say what the shape is FOR: which decisions were taken, what was rejected and on what grounds, and what would break if someone quietly undid them.

Write it when there is something to say. Design decisions belong here at the point they are made, not reconstructed later from the code that resulted.

**It ships with no design in it, on purpose.** A skeleton of headings and placeholder trees reads as a specification the project never committed to, which is worse than nothing.

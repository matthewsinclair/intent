# RULES.md

Project-specific mandatory rules for [[PROJECT_NAME]]. Every statement here is a "must" or a "never".

The four cross-language principles -- Highlander, PFIC, Thin Coordinator, No Silent Errors -- are stated in `AGENTS.md` under "Rules of the Road", with their rule IDs, and are deliberately not repeated here. Read any of them with `intent claude rules show <id>`; `intent claude rules list --lang <lang>` filters to one language.

This file is for what is true of THIS project and nothing else.

**It ships with no rules in it, on purpose.** A rule nobody has written is better than a rule nobody meant, and a heading waiting to be filled reads as a commitment the project has not made.

# This host's slot coordinator

This file is the Claude Code overlay on `AGENTS.md` beside it, which the `@AGENTS.md` line at the top of this file loads. The contract is there; this file adds what is Claude Code's alone.

## Required on every session

Run `/in-session` at session start and after every `/compact`, then follow the contract's session start. A compact does not end the session, so control stays taken; after one, check that the watch is still armed.

## The watch

Arm `intent estate slots watch` with the Monitor tool, so each line it prints wakes this session. Each line's first word is its step: act on `asked:` lines, the asks to judge, and on `ended:` and `revoked:` lines, which free capacity for the next grant. Your own grants and denials appear as well.

## Hooks

`.claude/settings.json` wires the same `intent claude hook` lifecycle hooks a project gets, so the prompt hook names the asks waiting for this session on every prompt.
